## How to Run & Build

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the website.

### Production Static Export
```bash
npm run build
```
Static production files are generated into the `out/` folder, ready to be hosted on any static hosting service (GitHub Pages, Netlify, Vercel, Cloudflare Pages, Apache, Nginx, or AWS S3).
